# 금리 원인 분해

매일 미 10년물 금리 변화를 **물가지표(CPI·PPI·PCE) / 지정학·유가 / AI(주가 동행) / AI(조달) / 연준·고용 / 기타(텀프리미엄·수급·재정)**로 나누고,
그날 AI 주식(SMH)과 나머지(RSP), 다음 날 코스피·하이닉스가 어떻게 반응했는지 같이 기록한다.
전무님 질문 "이번 금리 상승은 조달 때문이냐 인플레 때문이냐"를 매일 숫자로 보는 도구.

## 실행

```bash
python decompose.py
```

- `output/금리분해.html`: 오늘 카드, 기간별 분해(5일·20일·60일·9/22 이후·1년), 일별 분해 차트(60일), 최근 20일 표, 판정별 시장 반응(1년)
- `output/금리분해_일별.csv`: 1년치 일별 표(엑셀로 열림)
- 화면에 텔레그램용 요약 출력

텔레그램으로 바로 보내기(`../수급캘린더/.env`의 토큰·Chat ID 사용):

```bash
python decompose.py --send
```

봇을 켜두면 `/rates` 명령과 화~토 07:40 자동 발송이 된다(`../수급캘린더/config.py`의 `RATES_SEND`).

## 어떻게 나누나

1. **사실**: Δ10Y = Δ실질금리 + ΔBEI(기대인플레). 미 재무부 고시 금리(명목·실질 커브 CSV).
2. **같이 움직인 몫(회귀)**: 최근 120영업일 회귀 `Δ10Y ~ 브렌트% + (SMH−RSP)%p`의 계수 × 그날 값.
   - 계수는 전날까지 데이터로만 추정(오늘 값으로 오늘을 설명하지 않음).
   - **인과가 아니라 '시장이 그날 금리를 무엇과 묶어서 움직였나'**를 잰다.
3. **설명 안 된 나머지**는 그날 일정으로 배정: CPI·PPI·PCE 발표일 → 물가지표, FOMC·고용 → 연준·고용, AI 대형 회사채 발행일 → AI(조달), 그 외 → 기타.
4. **판정 라벨(하루 한 개)**: 물가지표 / 연준·고용 / AI 디그로싱 / 지정학·유가 / 지정학·안전자산 / AI 조달 / AI 성장 / 텀프리미엄·수급 / 연준 경로 / 기타·혼합 / 횡보.

## 직접 손볼 곳 (config.py)

- `TH`: 판정 임계값. **전부 AI 참고 제안**이라 무엇을 신호로 볼지는 직접 정해서 고친다.
- `AI_ISSUANCE_DATES`: AI 대형 회사채 발행일. 새 딜이 나오면 추가해야 'AI(조달)'이 잡힌다(2025년분은 기억 기반이라 보도로 확인 필요, 2026년분은 비어 있음).
- `CPI_DATES` 등 발표일: 연 1회 BLS·BEA 일정으로 갱신.
- `LEG_START`: '이번 레그' 누적 기준일(지금은 9/22, 리서치가 본 텀프리미엄 레그 시작).

## 한계

- 미 재무부 금리는 소수 둘째 자리라 bp가 정수로 나온다.
- 미 채권 휴장일(콜럼버스데이·재향군인의날)은 금리가 없어 판정하지 않는다.
- 같은 '기타' 안에 재정·국채 공급·글로벌 장기물·AI 조달(발행일 미기재분)이 섞여 있다. 텀프리미엄 레그를 더 쪼개려면 ACM 텀프리미엄, 입찰 결과, JGB·Gilt를 붙여야 한다(02 문서 4장).
- 유형별 표본이 작아(몇 일~수십 일) 판정별 평균 반응은 '방향 감' 정도로만 쓴다.
